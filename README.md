## 1. Project Overview & Clinical Context

This web application represents the full production-ready implementation of the final-year research project:
> **"Digital Twin-Based Intelligent Hospital Resource Optimization Using Explainable Multi-Agent AI"**

Centered on the **Emergency Treatment Unit (ETU) and Accident Ward at the National Hospital of Sri Lanka (NHSL), Colombo**, this platform bridges clinical hospital operations with predictive and prescriptive intelligence:
- **100% Visual Fidelity to Google Stitch UI:** Every single visual design token, typography hierarchy (Inter), color palette (`#004357`, `#0d5c75`, `#f8f9ff`), component padding, badge, card, and layout from Google Stitch has been strictly preserved.
- **Explainable Multi-Agent AI (XAI):** Incorporates multi-horizon demand forecasting with TreeSHAP feature attributions, real-time 40-bed telemetry, OR-Tools Mixed-Integer Linear Programming (MILP) resource allocation, Colombo disaster stress-testing, and acuity-weighted load balancing.
- **Human-in-the-Loop (HITL) Governance:** Every clinical advisory generated by the AI models includes mandatory clinician review gates (Approve / Reject / Override) backed by an immutable regulatory audit trail.

## 4. Multi-Agent AI Architecture

The system coordinates 6 explainable AI agents:

1. **Agent 1: Multi-Horizon Inflow Forecaster (XGBoost + TreeSHAP)**
   - Predicts patient arrivals across 4 discrete time horizons (+4h, +8h, +24h, +48h).
   - Explains predictions through TreeSHAP feature attributions (Heavy Rainfall Index, Sunday Evening Surge, Expressway Traffic Volume, Colombo Holiday Multiplier).
2. **Agent 2: Resource Monitoring & Telemetry Agent**
   - Continuously monitors 40 physical beds and critical life-support equipment (mechanical ventilators, multiparameter monitors, defibrillators, syringe pumps).
3. **Agent 3: Recommendation Coordinator (Google OR-Tools MILP)**
   - Formulates Mixed-Integer Linear Programming models to resolve ward congestion ahead of predicted arrival surges.
   - Enforces Human-in-the-Loop (HITL) review: every action requires doctor or administrator authorization.
4. **Agent 4 & 6: SMARTSTRESS Colombo Hazard Simulation Engine**
   - Stress-tests ETU resilience under local disaster scenarios:
     - **Kelani River Monsoon Flood Surge:** +45% waterborne and leptospirosis cases.
     - **Southern Expressway (E01) Multi-Vehicle Pileup:** Immediate 18 Cat-1/Cat-2 polytrauma arrivals.
     - **Colombo District Dengue Outbreak:** Sustained 5-day platelet monitoring load.
     - **Cyclone Storm Surge:** Off-grid generator switchover and oxygen reserve depletion test.
5. **Agent 5: SMARTLOAD Acuity-Weighted Workload Balancer**
   - Calculates cognitive load ratios per nursing station and suggests staff reallocations to prevent clinical fatigue.
6. **Digital Twin Engine (Discrete-Event Queue Simulator)**
   - Models patient stochastic queueing dynamics through Triage $\rightarrow$ Resuscitation $\rightarrow$ Monitored ETU $\rightarrow$ Inpatient Ward/Discharge.

## 5. Security & Role-Based Access Control (RBAC)

- **Password Encryption:** Salted PBKDF2 derivation with 100,000 iterations of SHA-512.
- **Session Security:** Cryptographically signed HMAC-SHA256 tokens stored in HTTP-only, SameSite cookies.
- **Account Verification Statuses:** `APPROVED`, `PENDING`, `DISABLED`.

## 6. Setup & Execution Instructions

### Prerequisites
- Node.js 18+ (tested on Node v24)
- npm 10+

### Installation & Database Setup
```powershell
# 1. Sync dependencies (if not already installed)
npm install

# 2. Push schema to SQLite database
npx prisma db push

# 3. Seed demonstration data (users, 40 beds, sample patients, recommendations)
node prisma/seed.js
```

### Running the Application
```powershell
# Production Mode (Recommended)
npx next build
npx next start -p 3000

# Or Development Mode
npx next dev -p 3000
```
Open **`http://localhost:3000`** in your browser.

### Running End-to-End Verification Tests
A full end-to-end test suite is included in `test-e2e.mjs`:
```powershell
node test-e2e.mjs
```
*Executes 41 automated tests verifying Authentication, RBAC, Patient Registration, Discharges, Analytics, AI Reviews, CSV Ingestion, and Audit Logging.*

## 7. Audit Logging & Compliance

All actions within the platform are logged into the immutable `AuditLog` table:
- Clinical Patient Intake & Unique ID Generation
- Patient Discharge & Bed Turnover Initiation
- AI Recommendation Approvals, Rejections, and Overrides
- Historical CSV Dataset Imports with provenance tracking
- Administrative User Status Changes & Role Elevations
- User Authentication Events (Success & Failures)
